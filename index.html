01 · Sobre

Backend é onde eu penso melhor.

Sou desenvolvedor especializado no ecossistema .NET, com foco em construir sistemas que não param: APIs REST bem desenhadas, workers que processam filas de forma idempotente e microsserviços que se comunicam de forma confiável via Kafka e RabbitMQ. Gosto de arquitetura limpa, testes automatizados e observabilidade — projetos que aguentam produção, não só o "funciona na minha máquina".

Atendo como desenvolvedor autônomo para empresas e squads que precisam de uma API nova, um serviço de processamento assíncrono, ou ajuda para desenhar/migrar uma arquitetura de monolito para microsserviços.
